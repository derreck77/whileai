# WhileAI 原型 v0.2：群組 × 互相出題｜User Stories（草稿）

> 日期：2026-10-09｜狀態：待確認
> 概念：每個群組都是一個小社群，成員可以互相出題；題目在大家等 Agent 的空檔送到，答案匿名彙整。

## 角色

| 角色 | 說明 |
|---|---|
| **建立者** | 開群組、邀人的人（通常就是第一個出題者） |
| **成員** | 已加入群組、裝了 WhileAI 的工程師 |
| **出題者** | 任何一位發起題目的成員 |
| **受邀者** | 拿到邀請連結，但還沒裝 WhileAI 的人 |

優先級：**MVP** = 這個原型一定要有｜**P1** = 原型之後馬上補｜**P2** = 驗證成功後再做

---

## A. 建立與加入群組

| ID | User Story | 優先 |
|---|---|---|
| A1 | 作為**建立者**，我想要輸入名稱就建立一個群組並拿到邀請連結，以便馬上把同事拉進來 | MVP |
| A2 | 作為**成員**，我想要點邀請連結（或輸入邀請碼）就加入群組 | MVP |
| A3 | 作為**受邀者**，我想要不裝 App、直接在網頁上回答題目，以便先體驗再決定要不要裝 | MVP |
| A4 | 作為**成員**，我想要看到群組有幾個人，但看不到誰答了什麼 | MVP |
| A5 | 作為**成員**，我想要同時加入多個群組（例如團隊和社群） | MVP |
| A6 | 作為**成員**，我想要離開群組 | P1 |
| A7 | 作為**建立者**，我想要重設邀請連結或移除成員 | P1 |

**驗收條件**
- A1：建立後 3 秒內拿到可複製的連結；群組名稱 1–40 字。
- A2：已裝 App 的人點連結會直接開啟 App 並完成加入；同一個人重複加入不會被算兩次。
- A3：網頁可以看題目、回答、看開獎，並提示安裝 App；網頁回答和 App 回答算在同一個池子裡。

## B. 出題

| ID | User Story | 優先 |
|---|---|---|
| B1 | 作為**出題者**，我想要寫一個問題加 2–4 個選項，30 秒內就發出去 | MVP |
| B2 | 作為**出題者**，我想要選擇要發到哪個群組（如果我在多個群組） | MVP |
| B3 | 作為**出題者**，我想要設定截止時間（預設 24 小時），以便在需要時拿到結果 | MVP |
| B4 | 作為**出題者**，我想要看到回答進度（例如「5／8 人已答」），但看不到是誰 | MVP |
| B5 | 作為**建立者**，我想要新群組自動附上幾題起手題，以便群組一開就有東西可以答 | MVP |
| B6 | 作為**出題者**，我想要在還沒人回答前修改或撤回題目 | P1 |
| B7 | 作為**出題者**，我想要從範本挑題目（例如「要不要換工具」「sprint 回顧」） | P1 |
| B8 | 作為**出題者**，我想要把好題目「公開為範本」給其他群組用 | P2 |

**驗收條件**
- B1：問題 5–120 字；選項 1–40 字、不可重複。
- B4：只顯示人數，不顯示任何可辨識個人的資訊。

## C. 回答（核心體驗：在等待中完成）

| ID | User Story | 優先 |
|---|---|---|
| C1 | 作為**成員**，我想要在等 Agent 超過 8 秒時，才看到群組的待答題，以便不打擾我專心工作 | MVP |
| C2 | 作為**成員**，我想要點一下就答完，以便 3 秒內回到工作 | MVP |
| C3 | 作為**成員**，我想要略過一題，並讓它截止前在下次等待時再出現 | MVP |
| C4 | 作為**成員**，我想要 Codex 需要我時，題目卡片立刻收起 | MVP（原型已有） |
| C5 | 作為**成員**，我想要從選單列主動看所有待答題，以便今天沒用 Agent 時也能回答 | MVP |
| C6 | 作為**成員**，我想要在卡片上看到群組名稱和出題者，以便知道這題是誰問的 | MVP |
| C7 | 作為**成員**，我想要每天收到的群組題目有上限，以便不被洗版 | MVP |
| C8 | 作為**成員**，我想要在回答前就清楚知道答案是匿名的 | MVP |

**驗收條件**
- C1：等待不到 8 秒就結束的任務不顯示；兩張卡片之間至少間隔 3 分鐘（原型已有）。
- C3：被略過的題目，同一次等待內不再出現。
- C7：預設每人每天最多 5 題，超過的題目排隊到隔天。
- C8：卡片上固定顯示「匿名 · ≥3 人回答才公開」。

## D. 開獎

| ID | User Story | 優先 |
|---|---|---|
| D1 | 作為**成員**，我想要在截止時或全員答完時看到結果 | MVP |
| D2 | 作為**成員**，我想要回答不到 3 人時不公開比例，以便保護匿名性 | MVP |
| D3 | 作為**出題者與回答者**，我想要在下一次等待時看到「開獎了」的卡片 | MVP |
| D4 | 作為**成員**，我想要在選單列看到群組的歷史題目與結果 | MVP |
| D5 | 作為**出題者**，我想要一鍵複製結果卡，貼到 Slack 或其他地方 | P1 |
| D6 | 作為**成員**，我想要看到「你們群組 vs 其他群組」的比較（同一個範本題） | P2 |

**驗收條件**
- D1：結果顯示各選項票數、比例、回答人數／群組人數、截止時間。
- D2：回答不到 3 人時顯示「回答人數不足，未公開結果」，不顯示任何比例。

## E. 隱私與控制

| ID | User Story | 優先 |
|---|---|---|
| E1 | 作為**成員**，我想要確定**沒有任何人**（包括建立者和 WhileAI）的介面能看到誰選了什麼 | MVP |
| E2 | 作為**成員**，我想要把某個群組設為靜音，或暫停所有卡片 1 小時 | MVP |
| E3 | 作為**成員**，我想要確定 WhileAI 不會讀取我的程式碼、prompt 或專案內容 | MVP（原型已有） |
| E4 | 作為**成員**，我想要刪除我所有的資料 | P1 |

**驗收條件**
- E1：後端儲存「誰答過」用來避免重複回答，但查詢結果的 API 只回傳彙總數字；個人答案不出現在任何 API 回應中。

## 這次原型不做

- 「全體開發者」公開群組、每日一題
- 跨群組比較、公開範本（B8、D6）
- 贊助題目、付費方案
- 正式帳號系統（見待確認事項）
- Windows、Linux，以及 Codex 以外的其他 Agent
