# WhileAI

**等 AI Agent 工作的空檔，和朋友互相出題。**

你在 Codex 或 Claude Code 交辦任務後，常常要等它跑一陣子。WhileAI 會在這段空檔，在右上角送出一張小卡片，題目是你群組裡的朋友出的。點一下就答完，大家都答了就開獎。

- **預設匿名：** 匿名題至少 3 人回答才公開結果，沒有人能看到誰選了什麼。出題者也可以選擇具名（例如訂午餐），卡片上會清楚標示。
- **不打擾工作：** 任務超過 8 秒才出現；Agent 需要你時立刻收起；隨時可以略過或暫停。
- **不讀你的工作內容：** WhileAI 只接收「Agent 開始／完成」的事件，不會讀取你的程式碼、prompt 或專案。

## 開始使用

需要：Apple Silicon（M 系列晶片）的 Mac、macOS 13 以上，以及 Codex 或 Claude Code。

```bash
git clone https://github.com/derreck77/whileai.git
cd whileai
./setup.sh
```

朋友給了你邀請碼的話，直接帶在後面，裝完會自動加入群組：

```bash
./setup.sh K7P3QX9M
```

1. `setup.sh` 會檢查環境、編譯 App，並連接你的 Codex 和 Claude Code，第一次約需 1 分鐘。如果還沒裝 Xcode Command Line Tools，它會先跳出安裝視窗。
2. 選單列右上角出現 ⏳，小框框會請你確認暱稱（已經預先填好）。
3. 沒帶邀請碼的話：點 ⏳ →「我有邀請碼」→「貼上邀請」。

完成。之後只要 Codex 或 Claude Code 在工作，題目就會自己出現。

## 怎麼玩

所有操作都在選單列 ⏳ 的小框框裡完成，不需要開網頁。

| 想做的事 | 怎麼做 |
|---|---|
| 回答題目 | Agent 工作時，題目會自己跳出來，點一下就答完；還有其他題目時可以按「下一題」繼續 |
| 出題 | 點 ⏳ →「出題」。選一個情境範本、改一下問題就能發；在選項按 Enter 會新增下一個選項 |
| 建立群組 | 點 ⏳ → 群組旁的「建立」 |
| 邀請朋友 | 進入群組 →「複製邀請」，把整段訊息貼給朋友（裡面有邀請碼和安裝指令） |
| 加入朋友的群組 | 複製朋友傳來的邀請訊息 → 點 ⏳ → 群組旁的「加入」→「貼上邀請」 |
| 看自己出的題 | 首頁的「我出的題」會顯示幾人已答；點進去可以「提前開獎」或「撤回」 |
| 看結果 | 開獎時會自己跳出來；也可以在群組的題目列表裡看 |
| 暫時不想被打擾 | 首頁左下角「暫停 1 小時」，或在群組裡按「靜音」 |

點框框外面或按 Esc 就會收起。沒裝 App 的朋友，可以打開邀請訊息裡的連結，在網頁上回答。

## 可以出哪些題目

出題時可以先點情境範本，設定會自動帶入，內容都可以再改：

| 範本 | 適合 | 預設 |
|---|---|---|
| 🍱 午餐 | 「中午吃什麼？」 | 單選、具名、回答後立刻看結果、1 小時截止 |
| 🙋 揪團 +1 | 「誰要一起去買咖啡？」 | 單選、具名、即時、30 分鐘截止 |
| ⚡ 快速決定 | 「這個命名選哪個？」 | 單選、匿名、即時 |
| 🗓 喬時間 | 「幾點開會方便？」 | 多選、具名、即時 |
| 🌡 心情 | 「這週工作順不順？」 | 1–5 分評分、匿名、截止才開獎 |
| 🤐 匿名吐槽 | 「Agent 今天做過最蠢的事？」 | 文字回答、匿名、截止才開獎 |
| 🎨 畫圖 | 「用畫的：你現在的心情」 | 用滑鼠在小畫布上畫圖回答、匿名、截止才開獎 |
| ✏️ 自訂 | 其他任何題目 | 自己決定 |

每一題可以調整四件事：
- **題型：** 單選、多選、評分（1–5 分）、文字（最多 140 字）、畫圖（6 種顏色、粗細兩種筆，可以復原和清除；開獎時看到所有人的畫）。
- **匿名或具名：** 匿名題要滿 3 人回答才顯示結果，沒有人能看到誰選了什麼。具名題會在卡片上標示，回答前就知道大家會看到你的回答。群組不到 3 人時，出題會自動預設成具名，否則結果永遠不會顯示。
- **何時看結果：** 回答後立刻看，或等截止、全員答完才開獎。
- **截止時間：** 30 分鐘到 3 天。

## 支援的 Agent

| Agent | 題目會自動出現嗎 |
|---|---|
| Codex（CLI、桌面 App） | ✅ |
| Claude Code（終端機、IDE、Claude 桌面 App） | ✅ |
| 在雲端執行的 Agent（例如 Codex 網頁版） | ❌ 可以從選單列或網頁回答 |

## 移除

```bash
./prototype/uninstall.sh
```

這會移除 App、Codex 與 Claude Code 裡的 WhileAI 設定，以及開機自動啟動。加上 `--purge` 會連本機資料一起刪除。

## 專案結構

| 路徑 | 內容 |
|---|---|
| `setup.sh` | 一鍵安裝 |
| `whileai.json` | 正式伺服器網址 |
| `prototype/` | macOS 選單列 App（Swift）、安裝與移除腳本，見 [prototype/README.md](prototype/README.md) |
| `server/` | 後端 API 與網頁（Python 標準函式庫 ＋ SQLite） |
| `Dockerfile`、`railway.json` | 部署到 Railway 的設定 |
| `docs/` | 競品調查、User Stories |

這是原型階段的專案，歡迎回報問題或建議。
